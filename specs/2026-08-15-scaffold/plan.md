# Plan — Scaffold

## 1. Project init

1.1. Run `create-next-app` (TypeScript, Tailwind, App Router, ESLint) into
     the repo root.
1.2. Verify `npm run dev` boots the default template before customizing
     anything.

## 2. Tooling

2.1. Add Prettier config (`.prettierrc`) and align it with the ESLint config
     generated by `create-next-app` (avoid rule conflicts).
2.2. Add `typecheck` script (`tsc --noEmit`) to `package.json`.
2.3. Confirm `lint`, `typecheck`, and `build` all run clean on the untouched
     template.

## 3. Env template

3.1. Add `.env.local.example` with `GOOGLE_AI_API_KEY`, `ELEVENLABS_API_KEY`,
     `SOLANA_RPC_URL`, matching the top-level README's `.env.local` section.
3.2. Confirm `.env.local` (not `.example`) is gitignored.

## 4. App shell

4.1. Build `app/layout.tsx` with minimal shared chrome (title, base
     styling, font).
4.2. Build `app/page.tsx` with a simple step state (`generate | mint |
     fight | result`) and one placeholder component per step, swapped by
     that state — no transition animation yet, just correct rendering.
4.3. Create placeholder components: `GenerateStep`, `MintStep`, `FightStep`,
     `ResultStep` — each renders a heading and a "Next" button that advances
     the step state, so the shell is click-through testable end to end.

## 5. Dependencies for later phases

5.1. Install `framer-motion` (no usage yet — Phase 1+ will use it for
     reveal/transition polish).
5.2. Do NOT install Solana or Google AI / ElevenLabs SDKs yet — those land
     with their respective phases per requirements.md scope.

## 6. Verification

6.1. Run `npm run lint`, `npm run typecheck`, `npm run build` — all clean.
6.2. Run `npm run dev`, manually click through all four placeholder steps
     in the browser.
6.3. Cross-check against [validation.md](validation.md) before considering
     this phase done.
